IDEA常用插件

本文最后更新于：几秒前

高效提升 IntelliJ IDEA 开发效率的优秀插件推荐

🚀 核心效率提升插件

⌨️ Key Promoter X

帮你快速学会并使用 IDEA 的快捷键：每次用鼠标操作时弹出对应快捷键提示，让你逐渐抛弃鼠标操作，加快开发速度。 (Cratecode)

🧠 SonarLint

实时静态代码分析，在写代码时就发现潜在 Bug、代码异味和安全问题，保持代码质量。 (Cratecode)

🌈 Rainbow Brackets

彩虹括号，自动为不同层级的括号着色，代码结构一目了然，尤其在嵌套逻辑多时很管用。 (Cratecode)

🧬 CodeGlance

在编辑器侧边添加代码 “缩略图” 迷你视图，快速跳转大文件的结构。 (Cratecode)

🗃️ String Manipulation

字符串快速操作利器（大小写转换、编码/解码、格式化等），减少重复编码操作。 (DEV Community)

🔍 Grep Console

增强控制台日志筛选、突出显示和颜色高亮，使定位问题更快。 (Baidu Cloud)

📦 版本控制 & 项目辅助

🔧 GitToolBox

增强内置 Git 支持：自动抓取、内嵌 blame 注释、更好的状态显示等，提高版本控制效率。 (Cratecode)

📊 WakaTime

自动记录编码时间和习惯，帮助你分析效率（适合想提升自我管理习惯的开发者）。 (Toxigon)

🚀 Save Actions

保存时自动整理 imports、重格式化代码、执行自定义动作，节省重复操作。 (DEV Community)

🧩 代码简化 & 结构工具

🧾 Lombok

减少样板代码（如 getters/setters/构造函数等），让实体类更简洁注意：新版 IDEA 已内置支持 Lombok。 (Cratecode)

💡 MyBatisX / Mybatis Log Plugin

对 MyBatis 项目非常有用：自动生成 Mapper/SQL、日志显示等，大幅提升开发效率。 (Baidu Cloud)

🧪 ESLint

前端项目集成 ESLint 检查和快速修复提示，让前端代码质量更好。 (DEV Community)

📈 进阶 & 个性化插件（可选）

  • IdeaVim：添加 Vim 键位，提升键盘操作效率。 (sudarshandoiphode.hashnode.dev)
  • .ignore：更方便地管理 .gitignore、.dockerignore 等文件。 (IDC.Net)
  • Material Theme UI：界面美化插件，视觉体验提升（虽非直接提效，但舒服也能间接提高效率）。 (Medium)
  • Translation：快速翻译文本，不用切出 IDE。 (blog.krybot.com)

📦 安装插件的小提示

插件安装路径：
File → Settings (Preferences) → Plugins → Marketplace → 搜索插件名称 → 安装 → 重启 IDEA。
